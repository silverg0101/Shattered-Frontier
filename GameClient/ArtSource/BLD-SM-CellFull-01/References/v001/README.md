# BLD-SM-CellFull-01 — v001

Appearance-only stone-masonry study for the proposed `cell-full` reference shape. It is a separately indexed material component study, not a complete architectural kit.

Design target: the same 0.5 × 0.5 × 0.5 m full-solid envelope, minimum-grid-corner pivot, six planar contacts and authored 90° grid orientations as the rough-timber cell. All stone courses stay within the visual target envelope. Geometry remains `geometry-proposed`; images do not establish dimensions, masks, numerical mesh fit, collision, support or runtime clearances.

Gameplay profile remains Stone masonry per Construction Architecture §3.2; this appearance does not merge with or alter rough timber properties. The original Waystone turnaround is a stone material cue only and is unchanged.
