# BLD-RT-FaceExteriorCellFull-01 — v001

Separately indexed rough-timber exterior-face appearance reference on proposed `cell-full/v1`. Target envelope is 0.5 × 0.5 × 0.5 m with minimum-grid-corner pivot and six planar contacts; no surface detail changes its occupancy or contact masks. This is a skin/treatment role, not a new shape, voxel, collision volume or gameplay profile.

The concept views and clean cube were inspected. This package covers only this appearance role; interior, top, underside, ends, joints, openings, corners, transitions and assembly studies remain separately indexed. Geometry fit and runtime compatibility are not established.
