Planting direction: use seeded patches of dense wildflowers and mixed vegetation in grasslands, and deliberately composed beds/low borders near cottages and villages. `planting-settings.json` declares the seed, physical spacing/heights, patch sizes and featured locations; typed `planting_layout.py` validates it and excludes roads, shared `FOOTPATHS`, entrances, plot buffers and gameplay clearings. `import_village_gardens.py` incrementally migrates White Everlasting and Leafy Dandelions with dependencies; `dress_meadow_gardens.py` bakes the generated planting and tended beds into the owned level. The same seed preserves the layout between rebuilds; every client loads the same saved scenery. This is an authoring workflow, not runtime client randomness or a new gameplay system. Licensed `Garden/` content stays local alongside `Village/`.
