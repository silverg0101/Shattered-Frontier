# BeastfolkWarrior art source

`PixalMV-v002/source/BeastfolkWarrior.glb` is the original WSL Pixal export. `PixalMV-v002/BeastfolkWarrior.glb` and `.blend` are the existing normalized 1.85 m source. See `PixalMV-v002/review.md` and `review-sheet.png` for the review and limitations. `AutoRig-v002/SK_BeastfolkWarrior.fbx` is the mannequin-compatible import candidate; the report and motion previews require visual signoff before gameplay use.

The v002 coat correction is declared in `AutoRig-v002/coat-profile.json` (metres, bounded outer-skirt envelope, 0.18 maximum upper-thigh influence at the hem). `tools/Build-NpcAutoRig.py --coat-profile` blends those vertices toward pelvis/spine and removes stray limb weights while feathering the region edges. Rebuild in Blender 5.1 from the repository root with `blender -b --factory-startup --python tools/Build-NpcAutoRig.py -- --input GameClient/ArtSource/NPC-BeastfolkWarrior-01/PixalMV-v002/BeastfolkWarrior.glb --skeleton GameClient/ArtSource/Voidreign/Rider/SK_Mannequin-skeleton.json --clips GameClient/ArtSource/NPC-BeastfolkWarrior-01/MannequinClips/ThirdPersonIdle.fbx GameClient/ArtSource/NPC-BeastfolkWarrior-01/MannequinClips/ThirdPersonWalk.fbx --output <new-folder> --height 1.85 --triangles 50000 --name SK_BeastfolkWarrior --coat-profile GameClient/ArtSource/NPC-BeastfolkWarrior-01/AutoRig-v002/coat-profile.json`. The six freshly rendered old-rig walk views are in `AutoRig-v002/review-before/`; the matching corrected frames 1/6/13 are in `AutoRig-v002/review/`. The new report records 4,164 blended vertices, 49,999 triangles and no empty deform groups. The coat hangs more consistently through the walk; fur, foot contacts and fingers still need art review. No Unreal import was performed.
