# Silverbrook Firewood Stack (street prop)

Reference: `PropFirewoodStack-reference.png`, cropped from `docs/Game-Design/concept-art/Silverbrook/Street Props.png` (SHA-256s in `asset-manifest.json`). Original procedural geometry interpreting the sheet.

```
"C:/Program Files/Blender Foundation/Blender 5.1/blender.exe" -b --factory-startup -P build_propfirewoodstack.py
"C:/Program Files/Blender Foundation/Blender 5.1/blender.exe" -b --factory-startup SilverbrookPropFirewoodStack.blend -P review_propfirewoodstack.py
```

Writes `SilverbrookPropFirewoodStack.{blend,fbx,glb}` and `asset-manifest.json` (includes `placement`); the review renders `PropFirewoodStack-{Beauty,Front,Side,Rear}.png` and checks GLB/FBX reimport. Metres, Z up, front -Y, origin ground centre. Blender 5.1.1.

## Interpretation

- 1.98 x 1.1 x 1.6 m (slot 2.0 x 1.1 x 1.6). Dressed-stone footing, four oak posts with side plates and gable trusses at both ends, slate gable roof with the ridge running front to back so the open gable shows the log ends; bargeboards and a slate ridge cap.
- Two courses of 150-odd billets (round, half, quarter) with bark and pale split faces, the back course offset so there is no sight-line through. Cut ends face out.
- **Inferred:** depth (1.1 m), truss details, ridge cap.

## Limits

- Split faces are a plank scan; the cut ends use the self-made ring texture (UV centred on each billet's pith). Logs overlap each other slightly and are not watertight. About 6k triangles.
