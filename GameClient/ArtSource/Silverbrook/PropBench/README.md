# Silverbrook Bench (street prop)

Reference: `PropBench-reference.png`, cropped from `docs/Game-Design/concept-art/Silverbrook/Street Props.png` (SHA-256s in `asset-manifest.json`). Original procedural geometry interpreting the sheet.

```
"C:/Program Files/Blender Foundation/Blender 5.1/blender.exe" -b --factory-startup -P build_propbench.py
"C:/Program Files/Blender Foundation/Blender 5.1/blender.exe" -b --factory-startup SilverbrookPropBench.blend -P review_propbench.py
```

Writes `SilverbrookPropBench.{blend,fbx,glb}` and `asset-manifest.json` (includes `placement`); the review renders `PropBench-{Beauty,Front,Side,Rear}.png` and checks GLB/FBX reimport. Metres, Z up, front -Y, origin ground centre. Blender 5.1.1.

## Interpretation

- 1.8 x 0.35 x 0.5 m (slot 1.8 x 0.4 x 0.5). Thick (70 mm) chamfered oak seat plank on four stout legs splayed in both directions, through-tenoned with wedges, an end rail across each leg pair and a long stretcher, as on the sheet.
- **Inferred:** wedge detail and leg splay in depth.

## Materials

All CC0 Poly Haven scans; sources in `../materials-provenance.json`.

|---|---|

## Limits

- The sheet shows slab trestle ends; these are four separate splayed legs. Under 400 triangles.
