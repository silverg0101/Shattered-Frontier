# Terrain delta store (MVP backend slice)

`TerrainDelta` is a package-free model and in-memory store. `TerrainDelta.Postgres` uses the pinned Npgsql dependency. `Schema.sql` is an explicitly installed, version 1 schema; the store rejects missing, inaccessible, older, or newer markers. Apply and Compensate atomically write a region revision and an operation receipt. Replays return the receipt even when the caller's expected revision has become stale; changed payloads with the same operation ID fail. A compensation appends a tombstone and can target only an uncompensated edit from the same character and claim in the same region. Region reads return a head plus entries after `sinceRevision`; reads take no advisory lock. Writes take a per-region advisory transaction lock and use revision CAS.

The boundary accepts dig, raise, flatten, and paint. Identifiers are 1–128 ASCII letters, digits, `_`, `.`, `:`, or `-`. Region coordinates and integer anchor components are limited to ±32767 cells; magnitude is 1–32767 signed-density units. These are release-bound storage safety limits, not live balance controls. The caller must validate zone ownership, claim permissions, brush volume, protected geometry, terrain material palette, and completed cross-domain action before Apply. This store does not implement the World voxel codec, terrain shaping, collision, replay compaction, public-edit healing, or a service endpoint. The integer anchor identifies the edit in region cells; BLD-02's 50 cm claim anchor stays with the claim record.

Run `tools/Test-TerrainDeltaDurable.ps1 -EvidenceRoot <fresh child of Artifacts/Persistence/TerrainDeltaDurable>` for locked restore, private published test output, owned loopback PostgreSQL, replay/CAS, restart/tombstones, and newer-schema refusal. No backup/restore integration is included because the shared backup helper requires more than a one-line store-list addition.
