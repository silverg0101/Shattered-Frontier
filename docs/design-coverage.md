# Concept-to-design coverage

Audit date: 2026-10-17. DOC-01 author scope: documentation only. [Work plan](design-work-plan.md) owns follow-up priorities; [backlog] owns implementation tickets. The [concept](../concept.md) is the vision, not an implementation acceptance contract.

## Reading the matrix

**Specified** means the cited inspected section defines the bounded behavior or acceptance stated in that row; it does not certify the whole domain. **Deferred** means planning explicitly excludes that behavior from the current slice. **Unresolved** names an existing decision or a concrete discrepancy. **Uninspected** means an owner/reference is mapped but detailed coverage was not verified. A row can have different states for its MVP subset and later ambition. No runtime, engine, capacity, price or hosting verification was performed.

E1 = engine/movement; H2 = persistent housing/terrain; G3 = small-group alpha; C4 = capacity/final MVP; VS = vertical slice. These labels follow [backlog], “Priority and milestone vocabulary.” Later roadmap phases are not newly authorized work. Reserved domain documents were read only.

## Remaining audit boundaries and next priority

The matrix covers every concept section by tracing its bounded subset or marking unverified detail. It is not a whole-spec audit: protected Quest/Dungeon/Raid/Security/LiveOps/Analytics parts, most progression/item/recipe content, full PvP/crime/social modes, offline simulation and expansion content were not inspected. Domain entry mappings alone do not establish completeness. Scope exclusions are not defects.

Continue DOC-02/DOC-08 and DOC-03 for H2 decisions. For DOC-06, first use a small read-only packet to close the crime/PvP-mode/expedition ownership leads and COV-03's Analytics lookup; only confirmed missing contracts should become author tasks. Keep COV-01/02 in a later event-owner correction packet. E1 still needs DEC-01 toolchain evidence independently of this documentation audit.

Validation: relative link targets exist; cited inspected headings and backlog/VS IDs were checked against their source. No runtime tests were appropriate. Independent closure review is recorded in the work plan; coordinator owns work-plan/index changes.
