# Exchange PostgreSQL durability fixture

The fresh loopback cluster stopped immediately between item delivery and Exchange commit, and separately between a ledger tombstone commit and Exchange commit. Recovery settled or compensated each once. A buyer destination revision advanced after Begin; the receipt still reconciled by operation ID, action and exact item changes. Concurrent buyers produced one sale. Cancelled and expired listings returned escrow once; sold listing cancellation was rejected. The fixture uses separate Exchange and inventory credentials. Exchange has SELECT only on its schema marker, SELECT/INSERT/UPDATE on mutable tables and no DELETE. The inventory fixture credential retains the existing adapter's required DELETE and schema marker UPDATE privileges. `Exchange.Tests`, `InventoryLedger.Tests`, and `MvpJourney.Tests` passed with the pinned SDK. Earlier review-fixes roots `-01` through `-05` exposed privilege or fixture mistakes; all owned private storage was removed. Production authentication, worker fencing, escrow funding orchestration, automatic reconciliation, shared configuration publication and backup/restore remain integration work.
