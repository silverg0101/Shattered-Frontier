# Prop Image Prompt Template

Use this reusable prompt to create a modeling and rendering reference for one prop; see [README.md](README.md) for how the template fits the art-reference workflow.

```text
Create a clear visual reference sheet for one fictional placeable prop intended for later manual Blender modeling and rendering.

MAIN CONCEPT: [Describe the prop in one sentence.]

Treat the concept sentence as the source of truth for the prop's identity and defining features.
Infer all unspecified details into a coherent, useful object.
The working default is grounded high-fantasy frontier craftsmanship: practical materials, believable construction, restrained ornament, and visible evidence of how the object is made and used.
This is a proposed working default, not approved art direction.
Any attached existing project art takes precedence for its established visual language.
Use its appearance, materials, and mood only; do not reproduce reference typography, logos, or collage layout.

Show the same single asset consistently in every view.
Unless the concept calls for another scale, make it roughly human-scale and plausible to place or use in a frontier setting.
Keep its silhouette distinct and its base stable on a level surface.
Let the concept override these defaults wherever it specifies otherwise.

Present a clean reference sheet with:
- A large three-quarter view as the primary view.
- Front, side, and rear views; include a top view if it helps explain the shape.
- A detail view only where a feature, join, or useful opening needs clarification.
- A small contextual view showing the object's scale and practical use, if that can be shown without changing the asset.

Keep all views visually consistent in shape, dimensions, materials, colors, and construction.
Make the object's useful function and contact points clear.
Show stable support, plausible joinery, attachment points, panels, handles, lids, or moving parts when applicable.
Explain how parts meet and how the object stands or rests.
Avoid floating components, unsupported spans, and mechanisms that appear impossible to build or operate.

Use materials that communicate their likely equivalents, such as wood, stone, metal, leather, glass, ceramic, rope, or cloth when suitable.
Keep surfaces purposeful and readable.
The object should appear intact and useful; do not make everything automatically medieval, broken, or weathered.
Apply wear only where use and material make it plausible.
Do not add people, unrelated equipment, text, labels, logos, or invented insignia.

Use a plain neutral background, even soft lighting, and restrained shadows.
Keep reflections controlled so surfaces, material boundaries, and construction details remain visible.
Frame every view with comfortable margins.
Show the full prop and its base without cropping.

Include a simple scale cue in meters and make dimensions believable relative to an adult human.
The scale cue is an approximate visual aid, not a claim of exact measurement.
Do not imply that the image is a mesh, a CAD model, or a dimensionally exact orthographic drawing.

Prioritize a useful, consistent reference for a human artist to interpret and model later.
Avoid action scenes, dramatic perspective distortion, cluttered environments, unsupported details, and visual effects that hide the object's form.
```

The generated image is a visual reference only; verify dimensions, stability, joinery, clearances, and modeling details before building the asset in Blender.
