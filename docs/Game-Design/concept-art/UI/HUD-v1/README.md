## Compact style guide

- **Palette:** background/panels `#17232A` (translucent slate navy); frame `#A98A55` (aged brass); accent/valid state `#688267` (moss); health `#A34842` (deep crimson); stamina `#B69A55` (muted amber); text `#E8E1CE` (warm ivory). Scene colours stay natural: forest greens, grey stone, weathered timber, river blue.
- **Type:** restrained fantasy serif for primary titles, panel headings and target names; clean sans for counts, percentages, timers, keybinds and compact status text. Use clear size and contrast over scenery.
- **Frames:** thin brass outlines on translucent slate panels; slight chamfers or clipped corners; small engraved dividers and rare pale-stag marks. Avoid heavy ornament. Active selections gain a brighter brass edge.
- **Spacing:** roughly 24–32 px panel insets at 1536 px width; 12–18 px between controls; 16–24 px safe inset from screen edges. Keep the center of the world readable.
- **Icons:** naturalistic, hand-rendered silhouettes of tools, materials and construction pieces, with consistent angle, muted material colour and crisp readable shape at slot size.
