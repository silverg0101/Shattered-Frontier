# Boar dodge sandbox scope

Combat Damage, Mitigation and NPCs v1.0, Resolution pipeline and Random draws: a physical melee attack in the defender's 180-degree front arc checks dodge after hit and before crit. Every admitted hit attempt consumes five attacker-stream draws in hit, avoidance, crit, block and spread order; dodge uses the avoidance draw. The NPC combat defaults table specifies a fixed 0.03 dodge chance, never derived from ratings. Combat Attributes and Ratings v1.0, Avoidance, also specifies the 180-degree front arc.

`SB_Dodge` first exercised this avoidance outcome against a defensive boar. The server owns the draw and damage decision. A dodge consumes the swing, deals no damage, and starts the boar's ordinary one-threat engagement. The two-client scenario supplies a low first avoidance draw and a high second draw as development evidence; normal attacks use the attacker's stream.

The shared server resolution path now runs for admitted player melee, boar melee and training cast ticks in Greenlands and the sandboxes. It consumes the same five draws and orders miss, dodge, parry, crit, mitigation, block, absorbs, rounding and application. Greenlands enables the authored 0.03 boar dodge and 0.03 melee-archetype parry in the front arc. Its two-client boar netcheck supplies one low avoidance draw and two high draws, proving dodge, threat, two hits and replication before the existing kill/respawn sequence. The training casts and boar attacks use the common path with unavailable stat-driven outcomes disabled.
