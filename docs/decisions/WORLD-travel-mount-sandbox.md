# Travel mount sandbox scope

World, *Cells, Movement and Handoffs* v1.0, “Movement modes and base speeds,” “Mode transitions,” and “Mounts” define the tier-1 travel mount at 11.0 m/s, a 1.5 s stationary mount cast, a 20.0 m/s mounted cap, out-of-combat and dry/outdoor admission, voluntary dismount, and dismount on hostile damage or water deeper than 1.3 m. This sandbox exercises those values through an authority-owned mount state and two-client travel sequence. The sandbox grants its test character a tier-1 mount entitlement and pilot health only within `SB_TravelMount`; these are development fixtures, not a production account unlock or creature deployment. No mount art or Greenlands placement is in scope.

No owner value is needed for this isolated travel-mount rule. Production rollout still requires the existing account-unlock snapshot/content path and reviewed mount presentation.
